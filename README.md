# Golf Charity Platform

A Next.js + Supabase project deployed on Vercel.

## Features
- Subscription system
- Charity selection
- Draw engine with forced testing
- Winnings tracking
- Admin payout control
- Supabase backend integration

## Live Demo
[View the app here](https://golf-charity-platform.vercel.app)

## Tech Stack
- Next.js
- Supabase
- Vercel
